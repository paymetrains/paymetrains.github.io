# Archived legacy apps

These files are preserved for reference and are not part of the active app.

`legacy-apps/root-calculator/` and `legacy-apps/oldpayCalc/` hold the original calculator versions. `legacy-apps/roster-analyser/` holds the retired analyser UI, calculator page and bridge, and old OCR/conversion work. Archived interfaces are historical source snapshots; their old asset paths may require adjustment to run separately.

The active app and shared calculation engine live in `../roster-analyser/`. Its development server serves only that directory, so this archive is unreachable through it. Deploy only `roster-analyser/`, never this archive or the whole workspace.
